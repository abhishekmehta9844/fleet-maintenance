# AI Collaboration Log

This project was developed in collaboration with an AI assistant. Key workflows included:

* **Session 1 (Database & Setup):** Used AI to scaffold the FastAPI environment, write SQLAlchemy models representing the 5 core tables, and structure the Vite React frontend.
* **Session 2 (CRUD & UI):** Iterated on React components with AI to build the Vehicle forms and lists, utilizing Tailwind CSS for styling. Debugged initial CORS and UUID parsing errors.
* **Session 3 (Business Logic):** Prompted the AI to design a state machine for service tasks and build the logic to automatically update master vehicle odometer readings upon task completion.
* **Session 4 (Advanced Features):** Used AI to write the Python SQLite injection for the immutable audit trail, build the bulk-update frontend logic, and conditionally render the UI based on user roles.
